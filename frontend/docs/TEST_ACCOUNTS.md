## 4. Kịch bản demo gợi ý

1. **Ứng viên mới**: mở `/careers` (chưa đăng nhập) → tìm "backend" hoặc gõ không dấu "lap trinh" → xem tin → Đăng ký
   (tick đồng ý xử lý dữ liệu) → tải CV → Ứng tuyển. Vài chục giây sau chuyên viên thấy điểm AI.
2. **Chuyên viên tuyển dụng** (`tran.ha`): *Việc của tôi* → tin Backend → bảng Kanban, hồ sơ có cảnh báo CV bất thường →
   mở hồ sơ Lê Thị Ngọc Trâm (điểm AI, đánh giá, tab Hoạt động) → nộp đánh giá còn thiếu → chuyển sang Thư mời → soạn và gửi.
3. **Đại diện phòng ban** (`nguyen.long`): *Việc của tôi* → xác nhận giờ phỏng vấn của Hồ Thị Bích Ngọc → tạo yêu cầu tuyển
   dụng mới → xem *Kết quả tuyển dụng* của phòng.
4. **Duyệt yêu cầu** (`tran.ha`): Yêu cầu "Kỹ sư AI/Machine Learning" → Duyệt / Yêu cầu sửa; xem khối Lịch sử.
5. **Ứng viên có thư mời** (`tran.huy`): Thư mời → xem, tải PDF → Nhận việc → trang chào mừng.
6. **Quản trị** (`le.quan`): Tổng quan theo quý → Người dùng (mời, khoá, đổi vai trò / phòng ban) → Thông tin doanh nghiệp:
   đổi **màu thương hiệu** và thấy toàn bộ giao diện đổi ngay → Trang tuyển dụng (nền phần đầu trang, ảnh, phúc lợi, xuất bản)
   → Nhật ký hệ thống.
7. **Quyền riêng tư** (bất kỳ ứng viên): Hồ sơ → Dữ liệu & quyền riêng tư → xoá dữ liệu → hồ sơ bị ẩn danh ở phía tuyển dụng.

## 5. Tạo ứng viên mới bằng tay

Đăng ký ở `/register` cần mã OTP gửi qua email. Với email `example.com` thư không được gửi; kích hoạt bằng tay:

```bash
docker exec ats-postgres psql -U ats_user -d ats_auth -c \
  "update app_user set status='ACTIVE', email_verified=true where email='ten.moi@example.com'"
```
